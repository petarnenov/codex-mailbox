Make the assumptions explicit.

Scenario, not a promise

One machine-hour is one agent executing for one hour. Parallel agents add hours; these are not calendar hours or human effort. Defaults are illustrative, not calibrated.

Planning scenario only · not added to live scope

Model = issue count × hours per issue × review multiplier. Explicit issue estimates override defaults. Shared issue estimates are allocated equally across their projects.
